# Ensan Project

Ensan is a comprehensive humanitarian and NGO management system built with Laravel. This project handles volunteer management, donations, logistics, and more.

## 📁 Project Structure

The project follows the standard Laravel architecture with a dedicated space for maintenance tools:

- **`app/`**: Contains the core logic of the application (Models, Controllers, Providers).
- **`bootstrap/`**: Used by the framework for initialization.
- **`config/`**: Configuration files for database, mail, services, etc.
- **`database/`**: Database migrations, seeders, and factories.
- **`public/`**: The web root. Contains `index.php`, CSS, JS, and Images.
- **`resources/`**: Frontend views (Blade templates) and language files.
- **`routes/`**: Definition of all web and API endpoints.
- **`storage/`**: Compiled templates, file sessions, file caches, and other files generated by the framework.
- **`tests/`**: Automated test suites.
- **`maintenance/`** 🆕: A secure directory for administrative scripts, data fixes, and legacy tools.

## 🚀 Getting Started

1.  **Environment**: Copy `.env.example` to `.env` and configure your database.
2.  **Dependencies**: Run `composer install` to install PHP dependencies.
3.  **Key**: Run `php artisan key:generate`.
4.  **Database**: Run `php artisan migrate` to set up the database schema.
5.  **Serve**: Use `php artisan serve` to start the local development server.

## 🛠️ Maintenance Tools

Common maintenance tasks (like inserting mock data or fixing permissions) are located in the `maintenance/` folder. Please refer to `maintenance/README.md` for more details.
